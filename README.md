# 一键影院模式 (Theater Mode Chrome Extension)

[![Version](https://img.shields.io/badge/version-2.1.6-blue.svg)](manifest.json)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

一个优雅、沉浸式的 Chrome 浏览器扩展。自动检测网页上的视频播放器，提供一键全屏影院模式、iOS 锁屏美学音乐模式、高精度快捷键操控、外挂字幕支持及丰富的外观设置。

---

## ✨ 核心特性

- 🎬 **一键沉浸式影院模式**：当页面存在视频时，自动显示一键悬浮按钮，开启极致暗黑遮罩播放。
- 🎵 **iOS 锁屏美学音乐模式**：一键切换至 iOS 锁屏风格界面，上方实时呈现系统级数字时钟与日期，中央展示大圆角高保真封面卡片，背景自动提取当前画面主色调并施以动态高斯模糊。
- ⏩ **6向定位按钮与专属操控**：底部悬浮栏提供 `-10分` / `-1分` / `-10秒` / `+10秒` / `+1分` / `+10分` 的便捷定位与字幕加载按钮。
- ⌨️ **自定义快捷键**：支持自定义快进/快退触发按键（默认 `J` / `L`）及跨越时间段，按 `ESC` 随时退出。
- 💬 **外挂字幕支持与定制**：内置字幕解析与渲染能力，可个性化调整字体大小、颜色、背景透明度与位置。
- 💡 **网页背景灯光 (Ambilight 氛围光)**：动态提取视频色彩生成背景氛围灯光，具备边缘随机缓慢波动（灵动流光）呼吸效果。
- 📐 **自定义布局与留白**：在设置面板中可自由调节音乐模式封面宽度、四周 Padding 留白、时钟顶部 Offset 与模糊强度。
- 📜 **本地观看历史**：自动保存最近 90 条视频观看记录（包含网址链接、网页标题、观看日期时间），在设置弹窗中可一键跳转或管理。

## 🛠️ 安装与使用

### 开发者模式加载（本地安装）

1. 下载或 Clone 本仓库代码到本地。
2. 打开 Chrome 浏览器，地址栏输入并访问 `chrome://extensions/`。
3. 在右上角开启 **开发者模式 (Developer mode)**。
4. 点击左上角的 **加载已解压的扩展程序 (Load unpacked)**。
5. 选择本项目所在目录即可完成安装。

---

## ⚙️ 设置面板

点击浏览器右上角工具栏的插件图标即可唤起设置面板：

- **快进 / 回退步长与按键绑定**：灵活配置快跳数值。
- **遮罩层透明度**：实时调整背景沉浸度。
- **字幕样式设置**：自由定义外挂字幕视觉风格。
